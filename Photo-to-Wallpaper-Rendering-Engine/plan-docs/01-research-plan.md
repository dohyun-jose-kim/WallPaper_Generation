# 1단계 조사 계획

> 현재 실행 범위(2026-11-11): [Build and Compare 0.0.1](build-n-compare-0.0.1/README.md). 세로·가로 2장, 도구 5개, 총 54개 케이스이며 실패도 유지한다. 아래는 이전 조사/환경 기록이다. 10개·26개 제안, Miniforge 대안 및 이전 실행 순서는 현재 범위에 적용하지 않는다.

조사일: 2026-10-28 · 보고서 버전: 0.0.1

## 목표와 범위

Brave 기본 새 탭용 정적 1920×1080 이미지에서 원본 전체를 중앙에 선명하게 두고 여백을 채울 수 있는 재현 가능한 방식의 첫 실험을 고른다. Fuzzy는 확대 블러, 가장자리·반사 확장과 경계 혼합을, Glassy는 다층 블러·변위 굴절·색조·하이라이트·원본 보호 마스크를 조사한다. 브라우저 효과의 정적 저장 가능성도 확인한다. 생성형 아웃페인팅은 제외한다.

## 질문과 평가

1. 각 후보가 제공하는 연산과 직접 구현할 합성 규칙은 무엇인가?
2. JPEG/PNG 저장과 CLI·배치, macOS/Apple Silicon 설치 조건은 무엇인가?
3. 라이선스·예제와 에셋의 재사용 조건, 유지보수 신호, 구현 복잡도는 어떠한가?
4. 문서로 확인된 사실, 추론, 실행 미검증 사항을 구분할 수 있는가?

전체 후보를 비교하고 Pillow+NumPy와 libvips/pyvips를 심화한다. 셰이더 저장소는 최대 두 개만 살펴본다. 공식 문서와 라이선스를 우선하며 라이브러리 설치, 벤치마크, 렌더링과 사진 선정은 2단계로 남긴다. 결과는 [구현 원리와 출처](01-techniques-and-examples.md), [비교와 추천](01-findings-and-recommendation.md), [시각 보고서](research-0.0.1/index.html)에 기록한다.
