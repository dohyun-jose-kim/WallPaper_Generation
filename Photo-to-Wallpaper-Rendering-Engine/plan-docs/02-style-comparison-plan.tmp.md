# 2단계 스타일 비교 계획

> **초안 — 1단계 조사 결과 반영 전, 구현 착수 전**

Brave 기본 새 탭에 사용할 1920×1080 배경을 비교한다. 원본 전체를 중앙에 배치하고 화면 가로와 세로의 90% 이내로 제한한다. 원본은 선명하게 유지하고 남는 여백에는 은은한 유리 효과를 적용한다.

세로 사진과 가로 사진 각 1장에 유리 효과 3종, 블러, 갤러리 방식의 5가지 처리를 적용해 총 10개 결과를 만든다. 비교판, 재현 스크립트, 실행 기록을 함께 만들고 출력 크기·원본 보존·재현성·시각적 경계를 검증한다. 첫 평가 후 대표 사진 6장으로 비교를 확대한다.

## 미확정 제안

Python 3.12와 Python·Pillow·NumPy 조합, 효과별 수치 및 스크립트 인터페이스는 조사와 실험을 거쳐 정한다. 이 문서는 사진 선정이나 렌더링 구현을 승인하는 기록이 아니다.
